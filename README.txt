ШАХИ — TELEGRAM MINI APP (версія 3)
===================================

Це та сама гра, але переписана на JavaScript як міні-застосунок Telegram.
Нічого не потрібно запускати на комп'ютері: сайт лежить на GitHub, а гра
відкривається прямо в Telegram. Ви тицяєте на фігуру на дошці — і ходите
(можна й перетягувати). Ніяких чорних консолей.

ЩО Є
----
* Дошка світла (3 теми: Пісок / Зелена / Блакитна), чорні фігури з білим
  обведенням — добре видно на будь-якому полі. Дизайн у стилі chess.com.
* Гра з комп'ютером: 10 рівнів (кожен сильніший за попередній).
  Вибір кольору: білі / чорні / випадково.
* Гра з другом: вибір часу перед партією
    - швидка гра: 10 / 20 / 30 / 60 хвилин кожному на всю партію;
    - листування: 1 / 3 / 7 днів на кожен хід.
  Друг заходить за посиланням (кнопка «Надіслати в Telegram») або за кодом.
* Очки: перемога +10, нічия +5, поразка 0 (і з комп'ютером, і з другом).
* Профіль (рейтинг, партій, перемог, нічиїх, поразок) і таблиця «Рейтинг гравців».
* ПАРТІЯ ЗБЕРІГАЄТЬСЯ АВТОМАТИЧНО. Вийшли в будь-який момент — у головному
  меню з'явиться блок «Ваші партії» зі стрілкою «Продовжити».
  Партії з друзями зберігаються на сервері, тож видно їх на будь-якому пристрої.
* Адаптація під екран: вертикально — дошка зверху, ходи й кнопки знизу;
  горизонтально — дошка зліва, панель справа.
* Звуки, як за справжньою дошкою: дерев'яний стук фігури, гучніший — коли беруть фігуру,
  подвійний — рокіровка, дзвінок — шах, перетворення пішака, довгий глибокий звук — мат.
  Вимикаються в меню (Звуки: Увімк./Вимк.). Звуки створюються самою грою, окремих файлів немає.
  Перший звук з'являється після першого дотику до екрана (так вимагає Telegram/браузер).
* Мови: українська та English. Правила повні: рокіровка, взяття на проході,
  перетворення пішака, пат, 50 ходів, триразове повторення, нестача матеріалу.

Усе безкоштовно. Усього 3 кроки: GitHub -> Telegram -> (для друзів) Firebase.


КРОК 1. ВИКЛАСТИ САЙТ НА GITHUB (5 хвилин)
------------------------------------------
1. Зареєструйтесь на https://github.com (якщо ще нема акаунта).
2. Натисніть «+» (угорі справа) -> New repository.
   Назва: chess   |   Public   |   галочку "Add a README" НЕ ставте -> Create repository.
3. На сторінці репозиторію натисніть посилання "uploading an existing file".
4. Розпакуйте архів (на телефоні: Мої файли -> натисніть на архів -> Розпакувати).
   У ньому ВСІ файли лежать в одній папці, БЕЗ підпапок — і на GitHub їх теж треба
   класти просто в корінь, без жодних папок. Натисніть «choose your files», виділіть
   УСІ файли з розпакованої папки (index.html, style.css, app.js, chess.js, engine.js,
   worker.js, net.js, store.js, i18n.js, pieces.js, sound.js, config.js, .nojekyll,
   app_picture_640x360.png) і завантажте. Файли з тією ж назвою просто замінюються.
5. Внизу натисніть Commit changes.
6. Зверху: Settings -> ліворуч Pages -> у "Branch" виберіть main і папку /(root) -> Save.
7. Через 1-2 хвилини вгорі сторінки Pages з'явиться адреса:
        https://ВАШ_НІК.github.io/chess/
   Відкрийте її в браузері — має з'явитися меню гри. Скопіюйте цю адресу.


КРОК 2. ПІДКЛЮЧИТИ ДО TELEGRAM (3 хвилини)
------------------------------------------
Ваш бот (той самий, що вже є) стане «кнопкою запуску» гри.
У Telegram відкрийте @BotFather:
1. Надішліть /newapp  -> оберіть вашого бота.
2. Title: Шахи.  Description: Шахи в Telegram.
3. Photo: надішліть файл app_picture_640x360.png (є в архіві; розмір 640x360).
4. GIF: надішліть /empty.
5. Web App URL: вставте адресу з кроку 1 (https://ВАШ_НІК.github.io/chess/).
6. Short name: наприклад play. BotFather відповість посиланням:
        https://t.me/ІМ'Я_БОТА/play
   ЗБЕРЕЖІТЬ його — воно знадобиться в кроці 4.
7. Щоб гра відкривалася кнопкою зліва від поля вводу в самому боті:
   /mybots -> ваш бот -> Bot Settings -> Menu Button -> Configure menu button ->
   вставте ту саму адресу GitHub і назву кнопки «Шахи».
Тепер відкрийте бота в Telegram і натисніть кнопку «Шахи» — гра з комп'ютером вже працює.
Старий Python-бот більше не потрібен: його можна не запускати.


КРОК 3. ГРА З ДРУГОМ І РЕЙТИНГ: БАЗА FIREBASE (5 хвилин, безкоштовно)
---------------------------------------------------------------------
Щоб двоє людей бачили ходи одне одного, потрібна спільна база даних.
(Без цього кроку працює лише гра з комп'ютером і особистий профіль на пристрої.)
1. Зайдіть на https://console.firebase.google.com під своїм Google-акаунтом.
2. Add project -> назва chess -> вимкніть Google Analytics -> Create project.
3. Ліворуч Build -> Realtime Database -> Create Database -> регіон (europe-west1) ->
   "Start in test mode" -> Enable.
4. Відкрийте вкладку Rules, замініть усе на це й натисніть Publish:
        {
          "rules": {
            ".read": true,
            ".write": true
          }
        }
   (Це відкриті правила: для гри з друзями цього достатньо. Без цього тестовий режим
    вимкнеться через 30 днів.)
5. Вгорі вкладки Data скопіюйте адресу бази. Вона виглядає так:
        https://chess-xxxxx-default-rtdb.europe-west1.firebasedatabase.app


КРОК 4. ВПИСАТИ АДРЕСИ В НАЛАШТУВАННЯ
-------------------------------------
1. На GitHub у репозиторії відкрийте файл config.js -> олівець (Edit).
2. Вставте між лапками:
        FIREBASE_URL: "адреса бази з кроку 3",
        TG_APP_LINK:  "https://t.me/ІМ'Я_БОТА/play",
   Без слеша в кінці. Натисніть Commit changes.
3. Зачекайте ~1 хвилину, повністю закрийте й знову відкрийте гру в Telegram
   (якщо бачите стару версію — закрийте й відкрийте ще раз).


ЯК ГРАТИ З ДРУГОМ (одним посиланням)
------------------------------------
1. Грати з другом -> оберіть час і колір -> Створити партію.
2. Натисніть «Надіслати посилання другу» і виберіть друга в Telegram.
3. Друг просто натискає на посилання — гра відкривається, і він АВТОМАТИЧНО
   приєднується до партії. Нічого копіювати й вводити не треба. Партія починається.
4. Можна вийти — партія збережеться; повернутись через «Продовжити» в меню.
Якщо посилання не налаштоване (немає TG_APP_LINK у config.js), на екрані очікування з'явиться
поле: вставте туди посилання на вашу гру з BotFather (https://t.me/ІМ'Я_БОТА/play) — один раз.
Запасний варіант: у друга є кнопка «Приєднатися за кодом» (код видно на екрані очікування).
Пропозиція нічиєї й «Здатися» є. Час вичерпано -> поразка (нічия, якщо в суперника
немає матеріалу для мату). У листуванні таймер показує дні/години на хід.

ДОШКИ ТА АВАТАРИ
----------------
Дошка (меню, внизу): Пісок, Зелена, Блакитна та «Ексклюзив» — синьо-жовта, патріотична.
На панелі кожного гравця показується його аватар з профілю Telegram (у грі з комп'ютером —
ваш аватар і 🤖). Якщо аватара немає або його сховано в налаштуваннях приватності —
показується перша літера імені. Маленький кружечок на аватарі: білий — грає білими,
чорний — чорними.

ПЕРЕВІРКА ВЕРСІЇ ТА ДІАГНОСТИКА
-------------------------------
Унизу головного меню є маленький напис "v3.7" (версія). Якщо після оновлення файлів
там інша версія — Telegram показує стару копію: закрийте гру повністю й відкрийте
через 2-3 хвилини (GitHub оновлює сайт не одразу). Торкніться цього напису —
відкриється вікно діагностики (що саме відбувається з комп'ютером); зробіть його
скріншот і надішліть, якщо щось не так.

ВАЖЛИВО ЗНАТИ
-------------
* Застосунок не надсилає сповіщень «суперник пішов» (він працює без сервера).
  У листуванні заходьте в гру самі; у меню «Ваші партії» видно, де зараз ваш хід.
* Гра з комп'ютером зберігається на вашому пристрої (у Telegram цього пристрою).
  Партії з друзями й рейтинг — на сервері Firebase, їх видно звідусіль.
* У швидкій грі годинник іде весь час, поки настав ВАШ хід — навіть якщо ви закрили гру.
  Тому для коротких партій краще не виходити; для довгих обирайте листування.
* Чесність гри в Mini App базується на довірі між друзями (захисту від зламування
  рейтингу немає). Для закритого кола друзів цього достатньо.

ОНОВЛЕННЯ
